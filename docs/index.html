What it does

Campus feed

Browse categorized posts, search entries, and discover trending campus updates.

Anonymous concerns

Submit a concern pseudonymously and track its status with a one-time receipt code.

Events

Find university events, RSVP, view attendees, and export calendar reminders.

Community interaction

Comment, reply, like, repost, save posts, and personalize a student profile.

Moderation and safety

Admins review submissions, audit decisions, manage reports, and run content safety scans.

Insights

Track category volume, weekly activity, reaction totals, and export moderation data.

Tech stack

Next.js 16 React 19 TypeScript Tailwind CSS 4 Supabase PostgreSQL Supabase Storage Vitest Playwright

About this page

This is a static project page. The full LINC application needs a Node.js server for login, database access, API routes, and admin actions, so those features cannot run on GitHub Pages. The complete source is available in the repository.
