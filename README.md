# LINC

**Lasallian Information Network and Community** — a centralized campus information and student engagement system for De La Salle Araneta University.

Made by **Carlos S. Alcantara III**

LINC gives students one place to browse categorized campus posts, submit concerns anonymously, track those submissions with a receipt code, discover and RSVP to events, comment and react to posts, and receive activity notifications. Administrators can review submissions, moderate content, manage users and events, run safety scans, and export insights.

## Tech stack

- **Next.js 16** App Router with **React 19** and **TypeScript**
- **Tailwind CSS 4**
- **Supabase PostgreSQL** and **Supabase Storage**
- `postgres` for database access, `jose` for JWT sessions, and scrypt password hashing
- **Vitest** and **Playwright** for testing
